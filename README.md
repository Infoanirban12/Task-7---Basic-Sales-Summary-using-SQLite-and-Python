# Task 7 - Basic Sales Summary using SQLite and Python

## Objective
Connect a Python script to a SQLite database, query sales data, summarize total quantity and revenue, and visualize the results.

## Tools Used
- Python
- SQLite (`sqlite3`)
- Pandas
- Matplotlib

## Tasks Performed
- Created a SQLite database with sales data
- Queried total quantity sold and total revenue per product
- Displayed the data using print and bar chart
- Saved the chart as PNG
